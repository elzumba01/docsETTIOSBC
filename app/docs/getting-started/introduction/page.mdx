# Introduction to Ettios Blockchain

Welcome to the Ettios blockchain documentation. This guide will help you understand what Ettios is and how to start building on our EVM-compatible chain.

## What is Ettios?

Ettios is a high-performance, EVM-compatible blockchain designed for scalable decentralized applications. Built with developers in mind, Ettios offers:

- **Full Ethereum compatibility**: Deploy existing Solidity contracts with no changes
- **Low transaction fees**: Build cost-effective applications without high gas costs
- **Fast finality**: Transactions confirm in under a second
- **Scalable infrastructure**: Support for high transaction throughput
- **Developer-friendly tools**: Comprehensive SDKs and documentation

## Key Features

### EVM Compatibility

As an EVM-compatible blockchain, Ettios supports all the tooling from the Ethereum ecosystem:

- **Development environments**: Hardhat, Truffle, Remix
- **Libraries**: web3.js, ethers.js, wagmi
- **Wallets**: MetaMask, WalletConnect compatible wallets

### Performance and Cost

Ettios offers significant performance improvements over traditional blockchains:

- Transaction finality in less than 1 second
- Transaction costs that are a fraction of Ethereum mainnet
- High throughput to support applications at scale

### Robust Security

Security is at the core of Ettios design:

- Secure consensus mechanism
- Regular security audits
- Bug bounty program
