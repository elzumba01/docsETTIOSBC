## Using with Development Tools

### Hardhat Configuration

For Hardhat development environments, add the following to your `hardhat.config.js` or `hardhat.config.ts`:

```javascript
module.exports = {
  networks: {
    ettiosMainnet: {
      url: "https://rpc.ettios.network",
      chainId: 9988,
      accounts: [process.env.PRIVATE_KEY]
    },
    ettiosTestnet: {
      url: "https://testnet-rpc.ettios.network",
      chainId: 9989,
      accounts: [process.env.PRIVATE_KEY]
    }
  }
};
```

### Truffle Configuration

For Truffle development environments, add the following to your `truffle-config.js`:

```javascript
const HDWalletProvider = require('@truffle/hdwallet-provider');
const privateKey = process.env.PRIVATE_KEY || '';

module.exports = {
  networks: {
    ettiosMainnet: {
      provider: () => new HDWalletProvider(privateKey, 'https://rpc.ettios.network'),
      network_id: 9988,
      gas: 5500000,
      confirmations: 2,
      timeoutBlocks: 200,
      skipDryRun: true
    },
    ettiosTestnet: {
      provider: () => new HDWalletProvider(privateKey, 'https://testnet-rpc.ettios.network'),
      network_id: 9989,
      gas: 5500000,
      confirmations: 2,
      timeoutBlocks: 200,
      skipDryRun: true
    }
  }
};
```

### Foundry Configuration

For Foundry users, you can add Ettios networks to your configuration:

```toml

```

## Example RPC Request

Below is an example of how to make an RPC request to check the ETT balance of an address:

```javascript
// Using fetch API
const response = await fetch("https://rpc.ettios.network", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    jsonrpc: "2.0",
    method: "eth_getBalance",
    params: ["0xYourAddressHere", "latest"],
    id: 1
  })
});

const data = await response.json();
// Convert result from hex to decimal and from wei to ETT
const balanceInEtt = parseInt(data.result, 16) / 1e18;
console.log(`Balance: ${balanceInEtt} ETT`);
```

### WebSocket Example

Here's a simple example of using WebSockets to subscribe to new blocks:

```javascript
const WebSocket = require('websocket').w3cwebsocket;
const client = new WebSocket('wss://ws.ettios.network');

client.onopen = () => {
  console.log('WebSocket connection established');
  
  // Subscribe to new block headers
  client.send(JSON.stringify({
    jsonrpc: '2.0',
    id: 1,
    method: 'eth_subscribe',
    params: ['newHeads']
  }));
};

client.onmessage = (message) => {
  const response = JSON.parse(message.data);
  if (response.method === 'eth_subscription') {
    const blockHeader = response.params.result;
    console.log(`New block: ${parseInt(blockHeader.number, 16)}`);
  }
};
```
