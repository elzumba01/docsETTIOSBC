# Deploying Your First Smart Contract

This guide will walk you through the process of creating, compiling, and deploying your first smart contract on the Ettios blockchain.

## Prerequisites

Before you begin, make sure you have:

- [Node.js](https://nodejs.org/) (v14 or later) and npm installed
- [MetaMask](https://metamask.io/) configured with Ettios network
- Some test ETT tokens for transaction fees (get them from our [faucet](/docs/getting-started/testnet-faucet))

## Setting Up Your Project

First, let's create a new project directory and initialize it:

```bash
mkdir my-first-contract
cd my-first-contract
npm init -y
```

Next, install Hardhat, which we'll use for development and deployment:

```bash
npm install --save-dev hardhat @nomicfoundation/hardhat-toolbox
```

Initialize a Hardhat project:

```bash
npx hardhat init
```

Choose "Create a TypeScript project" when prompted.

## Creating a Simple Smart Contract

Replace the contents of `contracts/Lock.sol` with the following simple greeting contract:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.19;

contract Greeter {
    string private greeting;

    constructor(string memory _greeting) {
        greeting = _greeting;
    }

    function greet() public view returns (string memory) {
        return greeting;
    }

    function setGreeting(string memory _greeting) public {
        greeting = _greeting;
    }
}
```

## Configuring Hardhat for Ettios

Update your `hardhat.config.ts` file to include the Ettios network:

```typescript
import { HardhatUserConfig } from "hardhat/config";
import "@nomicfoundation/hardhat-toolbox";
import * as dotenv from "dotenv";

dotenv.config();

// Get private key from .env file
const PRIVATE_KEY = process.env.PRIVATE_KEY || "";

const config: HardhatUserConfig = {
  solidity: "0.8.19",
  networks: {
    ettiosTestnet: {
      url: "https://testnet-rpc.ettiosblock.net",
      accounts: [PRIVATE_KEY],
      chainId: 9989,
    },
    ettiosMainnet: {
      url: "https://rpc.ettiosblock.net",
      accounts: [PRIVATE_KEY],
      chainId: 2237,
    }
  }
};

export default config;
```

Create a `.env` file in your project root to store your private key (never commit this file to version control):

```plaintext
PRIVATE_KEY=your_metamask_private_key_here
```

To get your private key from MetaMask:
1. Open MetaMask
2. Click on the three dots menu
3. Select "Account details"
4. Click "Export Private Key"
5. Enter your password and copy the private key

Install dotenv:

```bash
npm install --save-dev dotenv
```

Also create a `.gitignore` file:

```plaintext
node_modules
.env
coverage
coverage.json
typechain
typechain-types

# Hardhat files
cache
artifacts
```

## Writing a Deployment Script

Create a new file at `scripts/deploy.ts` with the following content:

```typescript
import { ethers } from "hardhat";

async function main() {
  // Get the contract factory
  const Greeter = await ethers.getContractFactory("Greeter");
  
  // Deploy the contract with the initial greeting
  console.log("Deploying Greeter...");
  const greeter = await Greeter.deploy("Hello from Ettios Blockchain!");
  
  // Wait for deployment to complete
  await greeter.deployed();
  
  console.log(`Greeter deployed to ${greeter.address}`);
}

// Execute the deployment
main().catch((error) => {
  console.error(error);
  process.exitCode = 1;
});
```

## Compiling the Contract

Compile your smart contract:

```bash
npx hardhat compile
```

## Deploying to Ettios Testnet

Deploy your contract to the Ettios testnet:

```bash
npx hardhat run scripts/deploy.ts --network ettiosTestnet
```

If successful, you should see output like:

```
Deploying Greeter...
Greeter deployed to 0x123...abc
```

Make note of the contract address for future reference.

## Interacting with Your Contract

Let's create a script to interact with our deployed contract. Create a new file at `scripts/interact.ts`:

```typescript
import { ethers } from "hardhat";

// The address where your contract is deployed
const GREETER_ADDRESS = "YOUR_DEPLOYED_CONTRACT_ADDRESS";

async function main() {
  // Connect to the deployed contract
  const Greeter = await ethers.getContractFactory("Greeter");
  const greeter = Greeter.attach(GREETER_ADDRESS);
  
  // Call the greet function
  const greeting = await greeter.greet();
  console.log("Current greeting:", greeting);
  
  // Update the greeting
  console.log("Setting new greeting...");
  const tx = await greeter.setGreeting("Hello from the updated Ettios contract!");
  
  // Wait for the transaction to be mined
  await tx.wait();
  
  // Get the updated greeting
  const newGreeting = await greeter.greet();
  console.log("New greeting:", newGreeting);
}

main().catch((error) => {
  console.error(error);
  process.exitCode = 1;
});
```

Replace `YOUR_DEPLOYED_CONTRACT_ADDRESS` with the address of your deployed contract, then run:

```bash
npx hardhat run scripts/interact.ts --network ettiosTestnet
```

## Verifying Your Contract (Optional)

If the Ettios block explorer supports contract verification, you can verify your contract to make it easier for others to interact with it:

```bash
npx hardhat verify --network ettiosTestnet DEPLOYED_CONTRACT_ADDRESS "Hello from Ettios Blockchain!"
```
